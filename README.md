## Setup

1. Drop `user.css` into your spicetify theme folder
2. Add `color.ini`'s `[YoRHa]` section into your spicetify `color.ini`
3. Run:
   ```
   spicetify config current_theme YoRHa color_scheme YoRHa
   spicetify backup apply
   ```
4. Relaunch Spotify
